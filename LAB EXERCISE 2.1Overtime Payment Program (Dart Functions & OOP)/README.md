
# TMA3084 SELAB - Lab 1

## Pizza Order Calculator

A simple Dart console application that calculates pizza order payments.

### Pizza Prices
- Small: USD 5
- Medium: USD 7
- Large: USD 10

### Features
- Accepts pizza size and quantity.
- Uses a switch statement to calculate payment.
- Uses while loops for input validation and repeated ordering.

### How to Run
Run the following command in the terminal:

dart main.dart
